# 🤖 بوت "جعفر" (Ja'far) — بوت الألعاب المصغرة لديسكورد

مشروع بوت ديسكورد متكامل مبني بلغة **Node.js** و **discord.js** مخصص لسيرفرات ديسكورد العربية، يركز على الفعاليات والمسابقات والألعاب المصغرة التفاعلية مع نظام نقاط وترتيب محلي.

---

## 🌟 مميزات البوت

- ⚡ **أداء عالي ومعالجة محلية بالكامل:** جميع خوارزميات الألعاب وقواعد البيانات تعمل محلياً بدون الاعتماد على أي API مدفوع أو خارجي.
- 🔤 **دعم متقدم للغة العربية:** معالجة دقيقة لعكس النصوص العربية وتسامح ذكي مع اختلاف الهمزات (أ، إ، آ)، التاء المربوطة (ة / هـ)، والياء/الألف المقصورة (ي / ى)، وال التعريف.
- 🎮 **ألعاب النسخة الأولى:**
  - 🔄 **لعبة "اعكس":** يرسل البوت كلمة أو عبارة عربية، وأول لاعب يكتبها معكوسة حرفاً بحرف يفوز بالنقاط.
  - 🚩 **لعبة "أعلام":** يعرض البوت إيموجي علم دولة من قاعدة بيانات محلية تضم أكثر من 70 دولة، وأول لاعب يخمن الدولة يفوز.
- 📊 **نظام نقاط ولوحة شرف (Leaderboard):** حفظ نقاط وفوز كل لاعب لكل سيرفر مع تفصيل النقاط حسب اللعبة.
- ⚙️ **إعدادات مركزية مرنة:** إمكانية تعديل مؤقت كل لعبة (افتراضياً 15 ثانية) ونقاط الفوز بسهولة من ملف الإعدادات المركزي أو لوحة التحكم.
- 🛡️ **حماية ضد التكرار والتعليق:** منع محاولات الإجابة المتكررة من نفس اللاعب في الجولة الواحدة، ومنع تداخل الألعاب في نفس القناة الصوتية/الكتابية.
- 🌐 **لوحة تحكم ومحاكي تفاعلي مدمج:** واجهة ويب تتيح تجربة الألعاب، فحص حالة البوت، ونشر أوامر السلاش بسهولة.

## 🛠️ متطلبات التشغيل وإعداد ديسكورد (Discord Setup)

### 1. إنشاء تطبيق البوت في ديسكورد:
1. توجه إلى [Discord Developer Portal](https://discord.com/developers/applications).
2. اضغط على **New Application** وسمّ التطبيق (مثلاً: `جعفر` أو `Jafar`).
3. من القائمة الجانبية، اختر **Bot**:
   - اضغط على **Reset Token** وانسخ التوكن (ضعه في متغير `DISCORD_TOKEN`).
4. **تفعيل الصلاحيات الخاصة (مهم جداً للعبة):**
   - في صفحة **Bot**، انزل إلى قسم **Privileged Gateway Intents** وقم بتفعيل:
     - ✅ **Message Content Intent** (ضروري لقراءة إجابات اللاعبين في الشات)
     - ✅ **Server Members Intent** (اختياري لقراءة أسماء وصور اللاعبين)
5. **دعوة البوت إلى سيرفرك:**
   - من القائمة الجانبية، اختر **OAuth2** -> **URL Generator**.
   - اختر Scopes: `bot` و `applications.commands`.
   - اختر Bot Permissions: `Send Messages`, `Embed Links`, `Read Message History`, `Add Reactions`, `Use Slash Commands`.
   - انسخ الرابط وافتحه في المتصفح لإضافة البوت إلى سيرفرك.

## ⚙️ متغيرات البيئة (.env)

قم بإنشاء ملف باسم `.env` في المجلد الرئيسي وضع بداخله:

```env
# توكن البوت من صفحة Bot في Discord Developer Portal
DISCORD_TOKEN="OTEx..."

# معرف التطبيق (Application ID) من صفحة General Information
DISCORD_CLIENT_ID="123456789012345678"

# (اختياري) معرف سيرفرك التجريبي لتسجيل أوامر السلاش فورياً
DISCORD_GUILD_ID="987654321098765432"

# منفذ لوحة التحكم والخادم
PORT=3000
```

## 🚀 التثبيت والتشغيل المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تسجيل أوامر السلاش (Slash Commands):
```bash
npm run deploy-commands
```

### 3. تشغيل المشروع:

#### تشغيل خادم الويب ولوحة التحكم والبوت معاً (Full-Stack):
```bash
npm run dev
```

#### أو تشغيل البوت كعملية مستقلة بدون واجهة ويب (Standalone Bot):
```bash
npm run bot
```

## 🌐 الاستضافة والإنتاج (Hosting outside AI Studio)

المشروع مصمم ليكون **محمولاً (Portable)** وجاهزاً للنشر المباشر على أي منصة:

### 1. على سيرفر VPS باستخدام PM2:
```bash
# تثبيت PM2
npm install -g pm2

# تشغيل البوت في الخلفية
pm2 start src/index.js --name "jafar-bot"

# حفظ التشغيل التلقائي عند إعادة إقلاع السيرفر
pm2 save
pm2 startup
```

### 2. على منصات السحاب (Railway / Render / Heroku):
- حدد أمر البدء (Start Command): `node src/index.js` أو `node dist/server.cjs`
- أضف المتغيرات `DISCORD_TOKEN` و `DISCORD_CLIENT_ID` في لوحة تحكم المنصة.
