# مجلد لوحة التحكم (Dashboard) - بوت جعفر

هذا المجلد مخصص للوحة التحكم البرمجية ومكونات الإدارة المستقبلية لبوت جعفر.

## الخصائص الحالية:
- واجهة تحكم متصلة بـ Express API في `server.ts`
- دعم مراقبة حالة البوت واتصال ديسكورد
- محاكي تفاعلي لتجربة ألعاب "اعكس" و "أعلام" بنفس منطق البوت الداخلي
- محرر الإعدادات المركزية (مؤقت الألعاب، النقاط، البادئة)
- لوحة الشرف واستعراض إحصائيات النقاط وسجلات السيرفرات
